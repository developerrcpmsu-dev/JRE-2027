# โฟลเดอร์สำหรับใส่ Web Icon & โลโก้เว็บไซต์ (Web Icons & Logos)
วางไฟล์ไอคอนและโลโก้ที่ต้องการใช้ในเว็บไว้ที่นี่ เช่น:
- favicon.ico / favicon.png (ไอคอนแท็บเบราว์เซอร์)
- logo.png / logo.svg (โลโก้โครงการ JRE 2027 / ตราสัญลักษณ์)
- badge.png (ตราสัญลักษณ์ชมรม/มหาวิทยาลัย)

เรียกใช้งานในเว็บผ่าน URL: /icons/ชื่อไฟล์.png
